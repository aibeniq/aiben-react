## 📄 CSV File Format

The generated VeraDoc CSV has the following structure:

| Checklist Question | Policy Context          | Citations                | Answer                | Final Evaluation           |
| ------------------ | ----------------------- | ------------------------ | --------------------- | -------------------------- | -------------------------- |
| Question text      | Relevant policy context | source1.pdf: citation \\ | source2.pdf: citation | Generated answer           | Overall evaluation summary |
| Question text 2    | Relevant policy context | source3.pdf: citation    | Generated answer      | Overall evaluation summary |

## 🎯 Key Features

- **Structured Export**: Each row represents one checklist question with its context, citations, and answer
- **Citation Formatting**: Multiple citations are pipe-separated with source filename prefixes
- **Final Evaluation**: The overall review summary is included in every row for context
- **File Naming**: Timestamped CSV files (e.g., `veradoc_review_20250628_143045.csv`)
- **Content Sanitization**: Removes newlines and carriage returns for proper CSV formatting
- **Error Handling**: Comprehensive error handling with user-friendly messages

## 🔄 Implementation Details

### Data Flow

1. User clicks "Download CSV" button in either review.tsx or archive.tsx
2. Frontend extracts QA pairs and final evaluation from results
3. Data is sent to backend as JSON: `{qa_pairs: [...], final_evaluation: "..."}`
4. Backend processes each QA pair into CSV rows with proper formatting
5. CSV is returned as a blob for download

### Citation Processing

- Extracts source file names from metadata paths
- Removes UUID prefixes if present
- Formats as "filename: content" and joins multiple citations with " | "
